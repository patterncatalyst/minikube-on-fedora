Appendix · Kubernetes patterns & CKAD

The patterns, worked with our own services.

A chapter per pattern across the six families of cloud-native Kubernetes design — foundational, structural, behavioral, configuration, advanced, and security — each one worked with the tutorial's shipping services instead of a textbook's toy app, and each cross-referenced to where it lands on the CKAD exam.

It's organized as its own set with its own reading order. Every chapter carries a CKAD exam lens and an Explore with your agent call-out, and a runnable example under examples/appendix-patterns/.

Where this fits in the tutorial

This appendix is reached from §18 of the main tutorial. The earlier sections stood up the cluster and its building blocks — kubectl, helm, Istio, KEDA — and the §17 capstone wired them into one running system. This appendix steps back and names the patterns behind those pieces, one at a time, with the CKAD exam as a second lens.

The examples run on a dedicated mof-patterns minikube profile, separate from the capstone's mof-capstone; the host prerequisites are the same as §1. This appendix stays on plain Kubernetes; the OpenShift Local (CRC) path is a separate corollary.
