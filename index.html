What you'll learn

How to install minikube on Fedora 44, run a local Kubernetes cluster with the docker driver and containerd runtime, and deploy applications with both kubectl and helm. Later sections cover Istio service mesh and (optionally) KEDA HTTP-driven autoscaling: reference material for using those tools against a local cluster. All container images are UBI-based and do not require Red Hat subscription registration. The guide finishes with two larger builds you can run end to end: a data-mesh final project and a Kubernetes design-patterns and CKAD appendix, each worked with the tutorial's own shipping services.

Two bigger builds

Beyond the core chapters, the guide carries two self-contained sets you can read and run on their own.

Final project

A data mesh on minikube

Every building block from the core chapters wired into one running system: services across REST, gRPC, GraphQL, and Kafka, deployed with helm, with contracts, a catalog, progressive delivery, autoscaling, and full observability.
